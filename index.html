🖥️ 32-bit x86 OS Emulator

A real x86-compatible CPU, emulated in your browser and running an actual 32-bit operating system — powered by v86, which JIT-recompiles x86 machine code to WebAssembly on the fly.

Pick an OS and click "Boot it". First boot needs to download the BIOS, CPU core, and disk image from the network (a few MB to ~50MB depending on the OS) — after that it runs entirely client-side.

Everything runs locally in your browser — no data leaves your machine once booted, and nothing is uploaded anywhere. This page loads the v86 emulator engine and OS images from public CDNs (jsdelivr, copy.sh) at runtime, so it needs an internet connection to start. Disk images are in-memory only; nothing is saved when you close the tab.
