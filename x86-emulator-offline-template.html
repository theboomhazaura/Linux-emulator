🖥️ 32-bit x86 OS Emulator

A real x86-compatible CPU, emulated in your browser and running an actual 32-bit operating system — powered by v86, which JIT-recompiles x86 machine code to WebAssembly on the fly.

This build has the CPU core, BIOS, and FreeDOS embedded — pick FreeDOS and click "Boot it" and it works with zero network, ever. KolibriOS and Linux still download their disk image once, then are cached for offline use after that.
File never leaves your browser — it's read locally and handed straight to the emulator as an in-memory buffer. Pick the right disk type: a Linux/Windows install ISO → "CD-ROM"; a raw hard-disk image → "Hard disk"; a boot floppy → "Floppy". Selecting a file overrides the preset dropdown above.

Everything runs locally in your browser — no data leaves your machine once booted, and nothing is uploaded anywhere. The v86 CPU core, BIOS, and the FreeDOS image are embedded directly in this HTML file (as base64), so booting FreeDOS works with zero network, ever — even opened straight from disk with no connection at all. KolibriOS and Linux are larger, so they still download their disk image from k.copy.sh the first time and are cached in your browser's Cache Storage after that (offline from then on, until you clear site data). Uploaded ISO/IMG files never touch the network; they're read straight from disk into memory.
